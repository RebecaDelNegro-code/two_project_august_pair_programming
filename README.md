💅 Studio de Nail Design & Gestão
Sistema profissional de gerenciamento e agendamento para estúdios de Nail Design, desenvolvido em Python utilizando a biblioteca gráfica tkinter e geração de dados fictícios com Faker.

🚀 Funcionalidades
Cadastro de Agendamentos: Insira o nome e o telefone da cliente de forma rápida.
Gerador de Dados Fictícios: Botão integrado com a biblioteca Faker (localizada para o português do Brasil - pt_BR) para preenchimento rápido de testes.
Seleção de Serviços/Estilos: Escolha entre diferentes modelos de unhas (como Glazed Donut, Ombre com Glitter, Metalizada e Abstrata Minimalista) com atualização dinâmica de preços.
Painel de Gestão: Tabela interativa (Treeview) com barra de rolagem para acompanhar todos os agendamentos realizados em tempo real.
Interface Moderna: Design limpo e intuitivo com tema personalizado utilizando ttk.
📋 Pré-requisitos
Certifique-se de ter o Python instalado em sua máquina (versão 3.6 ou superior recomendada).

Além disso, o sistema utiliza a biblioteca Faker. Instale-a executando o seguinte comando no seu terminal:

pip install Faker
